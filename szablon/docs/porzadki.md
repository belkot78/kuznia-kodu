# Porządki: odłożone uwagi

Uwagi nieblokujące z recenzji pakietów, jedna linia na uwagę, w sekcji „Z PK-XX”. Nie wracają do poprawek w pakiecie, który je zgłosił. Zbiera je `/kuznia:retro`.

Format linii: `[WAGA] plik:linia: problem i konsekwencja (status: otwarta / zamknięta w PK-YY)`.
